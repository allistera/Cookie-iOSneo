# Sidebar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The design's slide-over sidebar with Views, Labels and a read-only Drafts list, and folder switching for the mailbox.

**Architecture:** `Inbox` is generalised to `Mailbox` with a `MailboxFolder`; non-inbox folders render as one tab. `SidebarModel` owns the drawer state, labels and drafts. `DrawerContainer` is the one slide-over exception, wrapping `HomeView`'s navigation stack.

**Tech Stack:** Swift 6, SwiftUI, Observation, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-06-sidebar-design.md`.

## Global Constraints

- As in the earlier plans: Xcode 27.0, Swift 6 mode, no force unwraps, no lint suppressions, tests only in CI, format then lint before each commit, co-author trailer.
- Branch `sidebar`; pull request to `main`; do not merge.
- Strings in `Localizable.xcstrings`.
