# AI Today Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An AI Today screen showing the backend's inbox triage, with Refresh and cited emails that open the detail screen.

**Architecture:** `TodayModel` (`@Observable`) loads `GET /tasks` and posts `/tasks/refresh`. `EmailReference` builds an `EmailSummary` from a message id using the body endpoint's subject and thread rows, so `EmailDetailView` is reused unchanged. The sidebar gains `.today`.

**Tech Stack:** Swift 6, SwiftUI, Observation, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-06-ai-today-design.md`.
